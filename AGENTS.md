# Maintainer delivery contract

For every implementation milestone in this repository:

- Read `docs/ROADMAP.md`; distinguish software delivery from scientific validation.
- Update `README.md`, the stage/status record, affected methods/data/model-card documentation and verification evidence.
- Update the GB-FLEXABM case study in companion `abhijith-sivaprasadan.github.io`, its README, and discovery summaries where relevant. If that checkout is unavailable, report the pending update.
- Test scientific changes and GUI behaviour. Do not substitute simulated UI results for real runs. Keep normal CI independent of live APIs.
- Commit and push authorized changes in both repositories, check CI and verify Pages publication. Follow normal review protections; never force-push or bypass checks. Report local/unmerged work if publication is blocked.
- Preserve unrelated changes. Never publish private attachments, job descriptions, credentials, restricted data or scratch profile files.
- Do not claim calibration by changing labels. Preserve prior holdout exposure and failed gates.
